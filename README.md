# Братан-бот

Telegram-бот в стиле **Аой Тодо** из аниме «Магическая битва» — хвалит участников чата, реагирует на сообщения, показывает погоду, цитаты и факты.

---

## Возможности

### Команды

| Команда | Алиас | Что делает |
|---|---|---|
| `/братан` | `/bratan` | Хвалит случайного участника чата |
| `/погода <город>` | `/pogoda` | Текущая погода (Open-Meteo, без API-ключа) |
| `/факт` | `/fakt` | Случайная статья из русской Википедии |
| `/цитата` | `/quote` | Цитата культового аниме-персонажа |
| `/аниме <название>` | `/anime` | Инфо об аниме с оценкой и описанием (Shikimori API) |
| `/обнять <@user>` | `/hug` | Отправить аниме-гифку с обнимашками |
| `/погладить <@user>` | `/pat` | Погладить кого-нибудь |
| `/потыкать <@user>` | `/poke` | Потыкать кого-нибудь |
| `/кто <вопрос>` | `/kto` | Братан выбирает случайного участника |
| `/дуэль <@user>` | `/duel` | Аниме-дуэль — с @user или два случайных участника |
| `/топдуэль` | `/topduel` | Топ-5 победителей дуэлей 🏆 |
| `/курс` | `/kurs` | Курс USD, EUR, CNY от ЦБ РФ |
| `/мем` | `/mem` | Случайный мем |
| `/напомни через N ч M мин текст` | `/napomni` | Поставить напоминание |
| `/помощь` | `/pomosh` | Список всех команд |

### Автоматически

- **1 раз в день** (12:00–18:00 МСК) — похвала случайному участнику
- **2 раза в день** (12:00–18:00 МСК) — случайная цитата аниме-персонажа
- **В праздники** — тематические поздравления (Новый год, 23 февраля, 8 марта, 1 мая, 9 мая, 12 июня, 31 декабря)
- **На фото и стикеры** — текстовая реакция с вероятностью 15%
- **На текстовые сообщения** — emoji-реакция (🔥💯⚡🏆) с вероятностью 8%

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/danilastepanov/bratan-bot.git
cd bratan-bot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Создать `.env`

```env
BOT_TOKEN=your_telegram_bot_token_here
CHAT_IDS=your_chat_id_here
MEMBERS=@username1,@username2,@username3
TIMEZONE=Europe/Moscow
```

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `CHAT_IDS` | ID группового чата (можно несколько через запятую) |
| `MEMBERS` | Список участников через запятую (`@username`) |
| `TIMEZONE` | Часовой пояс (по умолчанию `Europe/Moscow`) |

### 4. Запустить

```bash
python bot.py
```

## Характер бота

Бот написан в стиле **Аой Тодо** — громкий, энергичный, называет всех братанами. Использует фразы: **БУГИ ВУГИ**, **САЙКО**, **резонанс душ**. Никаких романтических отношений — только братская любовь и боевой дух.
